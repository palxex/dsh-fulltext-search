# DeepSeek 官网「搜索对话」UI 规格（实测快照）

来源：https://chat.deepseek.com 顶部放大镜 → 输入「测试」。
测量时间 2026-10-01。用于对齐 dsh-fulltext-search 的搜索面板。

## 整体形态

**不是居中 Modal，是顶部悬浮面板**：
- 高 585px（内容少时仍保持较高）
- 白色 `rgb(255,255,255)`
- 阴影 `0 2px 4px rgba(0,0,0,.04), 0 4px 10px rgba(0,0,0,.02)`
- 页面其余部分变暗（遮罩）

### 宽度：响应式，不是硬编码 660px

实测方式：用 CDP `Emulation.setDeviceMetricsOverride` 改视口，逐个二分断点。

| 视口宽度 | 面板宽度 | 圆角 | top | 形态 |
|---|---|---|---|---|
| **≥768px** | **固定 660px**（居中） | 20px | 114px | 桌面悬浮卡片 |
| **<768px** | **铺满视口**（`left:0`） | **0px** | 0 | 移动端抽屉 |

断点实测：`768px` → 660px；`760px` → 铺满。故断点确切为 **768px**。

官网实现是 `.ds-modal-content` 上的 `max-width: 660px` + `--dsl-modal-*`
CSS 变量，配合媒体查询在窄屏切换为铺满/去圆角。
**注意**：≥768 时 `max-width` 计算值为 `660px`；<768 时 `max-width: none` 且
宽度等于视口 —— 说明窄屏不是「660 收窄」而是**另一套规则**。

本插件用等价规则复现：
```css
.dsss-card{width:660px;max-width:min(660px,calc(100vw - 32px));border-radius:20px;margin:114px auto 24px}
@media (max-width:767.98px){
  .dsss-card{align-self:stretch;margin:0;width:100%;max-width:100%;border-radius:0;max-height:100vh}
}
```

## 顶部输入行（高 61px）

| 元素 | 规格 |
|---|---|
| 容器 | `660 x 61`，底部 1px 分隔线 |
| 放大镜图标 | 36x36 圆形占位（radius 28px），内嵌 16x16 svg |
| 输入框 | **font-size 16px**，高 24px，宽 547px，无边框无背景 |
| 竖分隔线 | 1px x 20px，`rgba(0,0,0,0.04)` |
| 关闭按钮 | 32x28，radius 28px，图标色 `rgb(129,133,140)` |

placeholder：「搜索对话内容...」

## 结果行

| 元素 | 规格 |
|---|---|
| 行容器 | 高 **67px**，宽 644（面板 660 减左右 8px），圆角 **16px** |
| 行背景 | **`rgb(241,243,245)`** —— 注意：这是**选中态**背景（默认悬停/选中才显示） |
| 行内边距 | `10px 12px 10px 10px` |
| 行内间距 | `gap: 12px` |
| 左侧图标 | 36x36 圆形（radius 28px），内嵌 16x16 对话气泡 svg |
| 标题 | **font-size 15px**，font-weight 400，色 `rgb(15,17,21)`，高 25px |
| 日期 | **font-size 13px**，色 `rgb(129,133,140)`，右对齐 |
| 内容预览 | 等宽字体，形如 `<User>:回复·倍率测试<Assistant>:`，单行省略 |
| 子级指示 | 缩进的小图标 + 该会话的消息数 |

## 与当前实现的差异（待改）

当前 dsh-fulltext-search 用的是 `Modal`（居中对话框）+ `Input` + `Button`，表现为：
- 居中 480px 左右的小弹窗
- 有标题「会话全文搜索」和描述文字
- 有独立的「搜索」按钮，需要回车或点击

要对齐官网，需要：
1. 换成**顶部悬浮面板**（非居中），宽 660px，圆角 20px
2. 输入行 = 放大镜 + 无边框输入 + 分隔线 + ✕ 关闭，**去掉「搜索」按钮**（改为输入即搜/回车）
3. 结果行：36px 圆形图标 + 15px 标题 + 13px 日期 + 等宽内容预览
4. 选中行 `rgb(241,243,245)` 背景，圆角 16px
5. 键盘上下选择（官网支持）
